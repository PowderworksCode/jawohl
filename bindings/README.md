# jawohl, in other languages

Generated by [jedem][] from **one annotated Rust file**. `surface/src/lib.rs` is
the only thing here anybody wrote; the Python and Node crates beside it —
manifests, module shims, build script and binding source — are all generated.

```sh
cargo jedem run --python test.py
cargo jedem run --node test.mjs
```

```python
jawohl.complete_json('{"query":"rust par')       # '{"query":"rust par"}'
jawohl.status('{"n":10', "/n")                    # Syntax.Incomplete — 10 may become 100
jawohl.is_irrecoverable(schema, '{"role":"sup')   # True — stop generating
```
```js
jawohl.completeJson('{"query":"rust par')         // '{"query":"rust par"}'
jawohl.status('{"n":10', "/n")                    // "Incomplete"
jawohl.isIrrecoverable(schema, '{"role":"sup')    // true
```

Each language gets what it would have written: `snake_case` in Python and
`camelCase` in JS from the same Rust names, `Option<T>` arriving as `None` and
`null`, a `Result` raising a `ValueError` and throwing an `Error`, and **states
as real enums** — a `Syntax` class in Python, a string-literal union in
TypeScript — rather than strings that only convention keeps correct.

## What this is not, yet

**This is the batch-shaped subset.** jedem v1 exposes functions over plain
values — no handles, no streams, no callbacks — and jawohl's real API is a
stateful `Stream`, which is a handle. So each function takes everything received
so far and answers one question about it, which means **every call re-parses
from the beginning**.

For a tool call of a few hundred bytes that costs nothing, and the most valuable
question — *can this generation still succeed?* — answers fine that way. For a
long document it is quadratic, and the incremental `Stream` is what you want. It
arrives here when jedem grows handles.

## Layout

| | |
|---|---|
| `surface/src/lib.rs` | the only hand-written code |
| `surface/src/bin/jedem-generate.rs` | ten lines, mostly the macro call |
| `python/`, `node/` | **generated** — every file carries an `@generated` marker |

Regenerate with `cargo jedem generate`. A drift guard in CI fails if the
committed bindings no longer match the surface, and it covers every file jedem
writes, not just the binding source.

A **separate workspace on purpose**: the published `jawohl` crate gains no
dependency from any of this.

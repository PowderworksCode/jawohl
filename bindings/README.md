# jawohl, in other languages

Generated by [jedem][], from **one annotated Rust surface**. Nobody wrote the
Python or the Node binding; `surface/src/lib.rs` is the only hand-written file.

```sh
./run-python.sh    # builds the extension, runs a real Python process
./run-node.sh      # builds the addon, runs a real Node process
```

```python
import jawohl
jawohl.complete_json('{"query":"rust par')      # '{"query":"rust par"}'
jawohl.status('{"n":10', "/n")                   # 'incomplete' -- 10 may become 100
jawohl.is_irrecoverable(schema, '{"role":"sup')  # True -- stop generating
```

```js
jawohl.completeJson('{"query":"rust par')        // '{"query":"rust par"}'
jawohl.isIrrecoverable(schema, '{"role":"sup')   // true
```

Same functions, each spelled the way its language spells things: `snake_case`
in Python, `camelCase` in JS, `Option<T>` arriving as `None` and `null`, a
`Result` raising a `ValueError` and throwing an `Error`.

## What this is not, yet

**This is the batch-shaped subset.** jedem v1 exposes functions over plain
values — no handles, no streams, no callbacks — and jawohl's real API is a
stateful `Stream`, which is a handle. So each function here takes everything
received so far and answers one question about it, which means **every call
re-parses from the beginning**.

For a tool call of a few hundred bytes that costs nothing, and the most valuable
question — *can this generation still succeed?* — answers fine that way. For a
long document it is quadratic, and the incremental `Stream` API is what you
actually want. It arrives in these languages when jedem grows handles.

That limitation is the honest state of things rather than a presentation choice,
and it is why `is_irrecoverable` is the function these bindings exist for today.

## Layout

| | |
|---|---|
| `surface/` | the only hand-written code: `#[jedem::export]` over jawohl |
| `python/` | pyo3 extension module — `src/generated.rs` is generated |
| `node/` | napi addon — `src/generated.rs` is generated |

Regenerate with `cargo run -p jawohl-surface --bin generate`. A drift guard in
CI fails if the committed bindings do not match the surface.

This is a **separate workspace on purpose**: the published `jawohl` crate gains
no dependency from any of it.
